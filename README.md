# BEclean

BEclean is a backend service for a cleaning platform. It provides authentication, role management, service listings, order creation, and image uploads.

## Features
- JWT-based authentication and pre-authorization
- User roles: **admin**, **cleaner**, **client**
- Admin role management
- Cleaner sign-up flow
- Service management
- Order creation and management
- Image uploading for services

## Tech Stack
- Java
- Spring Boot
- Gradle
- JWT (JSON Web Tokens)
- REST API

## Getting Started

### Prerequisites
- JDK 17 or newer
- Gradle (the wrapper is included, so no separate installation is required)
